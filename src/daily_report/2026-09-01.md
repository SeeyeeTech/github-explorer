### 1. [Gitlawb/openclaude](https://github.com/Gitlawb/openclaude) · ⭐ 31093 · TypeScript · 新进榜 rank 1

Claude Code 的社区分叉，把终端编码 Agent 接到几十家 LLM 提供商。

要点：
- 支持 OpenAI 兼容端点、Gemini、GitHub Models、Bedrock/Vertex，以及 Ollama 本地无 key 运行；`/provider` 引导式配置写入 `.openclaude-profile.json`。
- 配置独立在 `~/.openclaude`，不读 `~/.claude`；要求 Node.js ≥ 22，非 Anthropic 模型下 WebSearch 降级为 DuckDuckGo 抓取。
- README 明示为非官方、与 Anthropic 无关联的社区分叉——上生产前请自行评估。

### 2. [Imbad0202/academic-research-skills](https://github.com/Imbad0202/academic-research-skills) · ⭐ 44698 · Python · 新进榜 rank 2

把论文流程拆成四个 Claude Code 技能：检索、写作、评审、修订到定稿。

要点：
- 四个技能分别是 13 agent 的 Deep Research、12 agent 的 Academic Paper、7 agent 的 Reviewer 和 10 阶段编排器；引用核验走 Semantic Scholar / OpenAlex / Crossref / arXiv。
- 作者定位「copilot, not pilot」，明说不保证实验真做过、数据真实或可复现；许可 CC BY-NC 4.0，仅限非商业使用。

### 3. [browser-use/video-use](https://github.com/browser-use/video-use) · ⭐ 22695 · Python · 新进榜 rank 9

让编码 Agent「读」视频而非看帧，用对话完成剪辑并输出成片。

要点：
- 两层上下文：默认只加载约 12KB 的词级时间戳转录，按需再生成某时间段的胶片图 + 波形 PNG。README 对比朴素方案「30,000 帧 × 1,500 tokens = 45M tokens of noise」。
- 流水线为转录 → 打包 → 推理 → EDL → 渲染 → 自评（最多循环 3 次），依赖 ffmpeg 和 `ELEVENLABS_API_KEY`。

📖 本站已有深度报告 → [browser-use 用 12KB 文本替代 4500 万 token，把 LLM 变成视频剪辑师](https://seeyeetech.com/github-explorer/reports/browser-use_video-use/)

### 4. [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) · ⭐ 112405 · 新进榜 rank 12

收集各品牌设计系统的 `DESIGN.md`，丢进项目让 Agent 生成对味 UI。

要点：
- `DESIGN.md` 概念出自 Google Stitch，规范含视觉主题、配色、字体、组件、布局、层级、do/don't、响应式和 agent 提示指引共 9 节，不需要 Figma 导出或 JSON schema。
- 每个条目附 `preview.html` 与 `preview-dark.html` 视觉目录；与 `AGENTS.md` 互补（一个管构建规则、一个管视觉规则），色值取自各站点公开 CSS。
