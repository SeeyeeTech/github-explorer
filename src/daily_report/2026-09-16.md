### 1. [alibaba/open-code-review](https://github.com/alibaba/open-code-review) · ⭐ 27.7k · Go · 持续上榜

阿里开源的代理代码审查工具：把确定性流水线（NPE、线程安全、XSS、SQL 注入等多语言规则集）与 LLM Agent 混合编排，输出精确到行级的评审意见，OpenAI / Anthropic 双兼容。结合确定性工程流水线与 LLM 代理，提供精确行级代码审查。

要点：不是又一个「LLM 提 PR 描述」玩具，而是把工程化「规则集 + LLM」范式推到阿里内部实战级；27.6k stars 的体量也说明这种「AI 不是替代工程化」的方向被广泛认同。

### 2. [pacifio/atlas](https://github.com/pacifio/atlas) · ⭐ 4.5k · Rust · 新进榜

「Source control for agents」——当 Claude Code / Codex / Cursor 多个代理在同一个仓库改代码，谁动了哪一行、何时用何提示词调的工具调用，全部留痕可查。为编程代理的提交提供版本溯源，保存提示与工具调用记录。

要点：首个把 Git 范式套到「代理工作流」的项目，呼应今日 earendil/pi 等代理工具链正在成为新基础设施的趋势。

### 3. [alphaXiv/OpenResearch](https://github.com/alphaXiv/OpenResearch) · ⭐ 3.1k · Rust · 新进榜

把现有编程代理改造成可复现的科研代理，自动产出文献综述与实验流程。让 Claude Code / Codex 之类的编程代理可以直接拿来做「带文献回链的科研报告」，定位是科研方向的代理技能插件。

### 4. [danny-avila/LibreChat](https://github.com/danny-avila/LibreChat) · ⭐ 43.7k · TypeScript · 新进榜

自托管多模型聚合聊天平台，统一接入 OpenAI / Anthropic / DeepSeek / Bedrock / Vertex 等多家 AI 提供商，加上 MCP / Artifacts / Code Interpreter 等界面能力，是「ChatGPT 替代品」赛道的成熟前端。

### 5. [MG1937/ASC](https://github.com/MG1937/ASC) · ⭐ 1.1k · Python · 新进榜
