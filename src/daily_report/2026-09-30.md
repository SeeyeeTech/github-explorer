## 🌟 开源新星

> 今日 Trending 里的 AI 新仓库（优先未被深度分析过的）

### 1. [paperclipai/paperclip](https://github.com/paperclipai/paperclip) · ⭐ 94167 · TypeScript · 排名 -2

把 Claude Code / Codex 编排成带预算与审批的公司化 Agent 团队。paperclip 把「在公司里怎么让多个 Agent 各司其职、互相审计、按预算执行」这件事做成开箱即用的开源自托管平台，是「Agent 框架 ≠ 智能体框架」这条线上少见的「公司化视角」作品。

要点：以「公司部门 / 预算 / 审批」为单位组织 Agent，贴近真实企业流程
要点：fork 16k+，被大量团队用作私有 Agent 中台二次定制
📖 本站已有深度报告 → [/reports/paperclipai_paperclip/](https://seeyeetech.com/github-explorer/reports/paperclipai_paperclip/)

### 2. [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight) · ⭐ 42434 · Python · 排名 0

类脑记忆让 Agent 在 LongMemEval 上夺冠，胜过普通对话回溯。hindsight 用一种受神经科学启发的存储结构，把「记住什么 / 何时该想起 / 怎么抑制过时记忆」拆成独立模块，替代「把整段对话塞进上下文」的暴力做法。

要点：在 LongMemEval 公开榜单上击败 Mem0、Letta 等对手
要点：定位「Agent 的海马体」，与 vectorize-io 的向量基础设施形成组合拳
📖 本站已有深度报告 → [/reports/vectorize-io_hindsight/](https://seeyeetech.com/github-explorer/reports/vectorize-io_hindsight/)

### 3. [NVIDIA/OpenShell](https://github.com/NVIDIA/OpenShell) · ⭐ 10277 · Rust · 新进榜

内核级沙箱为自治 AI Agent 强制权限策略，凭证按需注入目标端点。NVIDIA 首次下场做 Agent 运行时：把「Agent 在本机/远端到底能碰什么」做成可审计、可插拔、可被硬件信任根背书的执行环境，Rust 实现则把所有策略检查放在系统调用边界。

要点：把 NVIDIA 在机密计算 / 硬件信任根方面的积累平移到 Agent 运行时
要点：是少见的「Agent runtime」而非「Agent framework」——专注执行而非推理

### 4. [mvschwarz/openrig](https://github.com/mvschwarz/openrig) · ⭐ 2221 · TypeScript · 排名 +1

用 YAML 声明 Agent 团队，把 Claude Code 与 Codex 跑成同一系统。openrig 的赌注是「当 Claude Code 与 Codex 各自已经很强时，杠杆点不在单 Agent 的智能，而在它们协作的协议」——所以只做一件事，把多 Agent 编排声明式化。

要点：star 数仍低（2k），但作为「Claude Code × Codex 双体 harness」的代表信号值得观察

### 5. [VectifyAI/PageIndex](https://github.com/VectifyAI/PageIndex) · ⭐ 37042 · Python · 新进榜

用文档树索引替代向量库，让 LLM 像人一样推理长文档结构。PageIndex 不存 embedding，而是把 PDF/合同/财报的章节树序列化后让 LLM 沿着树状指针检索，在长文档「结构化推理」类任务上比传统 RAG 更稳。

要点：「Vectorless RAG」路线代表，把检索问题转化为「模型在大纲上的游走」
📖 本站已有深度报告 → [/reports/vectifyai_pageindex/](https://seeyeetech.com/github-explorer/reports/vectifyai_pageindex/)

### 6. [t8y2/dbx](https://github.com/t8y2/dbx) · ⭐ 21796 · Rust · 新进榜

25 MB 单文件支持 100+ 数据库的客户端，内置 AI 与 MCP 服务。dbx 把「跨数据库 + 内置 AI 助手 + MCP server」打包成单二进制，CLI / 桌面 / Docker 三种形态都有，国产「达梦数据库」被列进支持列表。

要点：对中文开发者最直接的卖点是「达梦数据库支持」
要点：MCP server 让任意 AI Agent 能直接调用数据库——属于 Agent 时代的数据库入口争夺战

### 7. [dream-num/univer](https://github.com/dream-num/univer) · ⭐ 21713 · TypeScript · 排名 -5

把电子表格/文档/演示嵌入自家产品的同构 Office SDK。univer 给 SaaS 厂商提供「内嵌一套不依赖微软/谷歌的 Office 套件」的能力，且按 AI Agent 时代的 API 重新抽象——所有单元格 / 段落都是结构化对象，Agent 能直接读写。

要点：把「AI 时代的 Office SDK」当成工程目标，而非简单复刻 Excel
📖 本站已有深度报告 → [/reports/dream-num_univer/](https://seeyeetech.com/github-explorer/reports/dream-num_univer/)
