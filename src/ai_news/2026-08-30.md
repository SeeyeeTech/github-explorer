### 行业与融资

#### 1. OpenAI 宣布终止对 Cursor 的模型供应（Our decision on Cursor following its acquisition by SpaceX）· 🔥 必看 8.6

OpenAI 在官方页面宣布，将结束向 Cursor 提供模型的合同，拟定关停日为 2026 年 11 月 12 日，理由是 Cursor 已被 SpaceX 收购，OpenAI 「无法确信 SpaceX 会在我们的服务条款内使用我们的技术」。这是头部模型商第一次公开以「新股东是谁」为由切断一家头部 AI 编程产品的供给——对所有把单一闭源模型当作唯一后端的产品来说，这是一次相当直接的供应链风险演示。

要点：
- 官方原文措辞是 wind down 合同 + 「proposed shutoff date」（拟定关停日），并非双方已确认的既成终止，日期理论上仍可能变动
- 收购一侧由 Cursor 官方博客独立确认：2026-08-14 发文《Cursor is now a part of SpaceX》，称收购流程始于 4 月的 SpaceXAI 合作
- Cursor 方至今未就断供发声，「11 月 12 日」目前只有 OpenAI 单方口径

### 模型与评测

#### 2. 智谱开源 GLM-5.3 与 GLM-5.3-Flash（GLM-5.3 / GLM-5.3-Flash）· 🔥 必看 8.4

智谱把旗舰 GLM-5.3（753B 总参、激活 40B）与多模态版 GLM-5.3-Flash（321B 总参、激活 18B）同时放上 HuggingFace，主打 Agentic Coding。最扎眼的是 Terminal Bench 3.0：GLM-5.2 只有 4.6 分，GLM-5.3 直接到 28.3——这不是常见的一两个点的迭代，而是长程终端任务能力的量级变化。Flash 版走 MIT 许可，对想自建 Agent 后端的团队门槛更低。

要点：
- GLM-5.3 用 glm_moe_dsa 架构（MoE + DeepSeek Sparse Attention）；Flash 走混合稀疏 + 线性注意力 + mHC
- 许可证不一致：GLM-5.3 是自定义 glm-5.3 协议，GLM-5.3-Flash 是 MIT，GitHub 仓库本身 Apache-2.0，商用前需分别确认
- HF 页写 753B，GitHub README 写 744B-A40B，为同一模型的取整差异

方法：MoE 稀疏注意力基座上做面向 Agentic Engineering 的 post-training。
指标：Terminal Bench 3.0 28.3（vs GLM-5.2 的 4.6）— [来源](https://huggingface.co/zai-org/GLM-5.3)
指标：CyberGym 84.5 — [来源](https://huggingface.co/zai-org/GLM-5.3)
指标：Terminal-Bench 2.1 88.2（Flash 版 84.3）— [来源](https://huggingface.co/zai-org/GLM-5.3)
链接：[模型](https://huggingface.co/zai-org/GLM-5.3) · [Flash 版](https://huggingface.co/zai-org/GLM-5.3-Flash) · [代码](https://github.com/zai-org/GLM-5)

### 论文前沿

#### 4. StateM：把预算花在 Harness 上，15 美元跑出 95.3%（StateM: Harness Scaling on Terminal-Bench）· 🔥 必看 8.0

UT Austin 团队提出 StateM，思路是不换更强的模型，而是扩展模型外面的 harness（状态管理与执行脚手架）。结果是 GPT-5.6 Sol xhigh + StateM 在 Terminal-Bench 2.1 拿到 95.3% 原始准确率；更有意思的对照是成本——用 DeepSeek-V4 Flash 跑完最终评分的 API 花费约 15 美元，而 GPT 参照组是 574.68 美元。对预算有限但想跑前沿级 Agent 评测的团队，这篇给出了一条可复制的省钱路径。

要点：
- 89 个任务在 445 次试验中全部至少成功一次
- 15 美元指的是最终评分那一次运行的 API 花费，DeepSeek 线路总花费为 52.22 美元，别混为一谈
- 代码已开源

方法：以 harness scaling 替代模型 scaling，通过外部状态管理放大既有模型的长程任务成功率。
指标：Terminal-Bench 2.1 原始准确率 95.3% — [来源](https://arxiv.org/abs/2608.15089)
指标：最终评分 API 花费约 15 美元（对照 GPT 参照组 574.68 美元）— [来源](https://arxiv.org/abs/2608.15089)
链接：[论文](https://arxiv.org/abs/2608.15089) · [代码](https://github.com/henryqin1997/statem)
来源：[arXiv 2608.15089](https://arxiv.org/abs/2608.15089) · [arxivtldr 摘要](https://arxivtldr.org/abs/2608.15089)
