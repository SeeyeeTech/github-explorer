### 模型与评测

#### 3. prime-agent 自称 ARC-AGI-3 拿 95.5%，官方榜单查无此项 · 🔥 必看 8.2

中文圈今天在传「开源 Agent 框架刷爆 ARC-AGI-3」。我们按流程去核验，结论是：**「刷榜」这个说法失实**。Prime Intellect 官方博客确实自报了 95.0% / 95.2% / 95.5% 三跑成绩，但 arcprize.org 的官方 leaderboard 截至核验时并未收录 prime-agent，该榜同期最高分是 Claude Opus 5（High）的 30.2%——两者相差不是几个点，是一个数量级。这条之所以进「必看」，不是因为成绩，而是因为它是今天最值得一看的**评测可信度案例**。

要点：
- 官方博客（2026-08-05）自报 Opus 5 + Prime Agent 的 RHAE Best@1 三跑为 95.0 / 95.2 / 95.5%，Best@3 达 99.97%（183/183 关）
- arcprize.org 官方榜单无 Prime Intellect / prime-agent 条目，榜首为 Claude Opus 5（High）30.2%（2026-07-24）
- Shortcut AI 联合创始人 Peter Wang 提出两点质疑：仓库中 `RLM_MAX_DEPTH=1`，所谓递归语言模型实为单主 agent 调子 agent；95.5% 取自公开评测集，Continual Harness 可挖掘历史轨迹做任务级过拟合
- Prime Intellect 联合创始人 Alex Zhang 部分认领：承认 ARC-AGI-3 是 exploitable benchmark，且 Continual Harness 的贡献可能大于 RLM 本身

方法：Continual Harness + 自我改进 RLM，在长程编码与自治任务上迭代改写自身策略。
指标：仓库 6,376 stars / 511 forks，MIT 协议 — [来源](https://github.com/PrimeIntellect-ai/prime-agent)

#### 4. DeepMind WeatherNext 登 Nature：气旋预报多拿一天提前期 · 🔥 必看 8.4

Google DeepMind 在 Nature 发表「Operational Tropical Cyclone Forecasting with AI」，把 AI 气象预报从「和物理模式打平」推到了业务可用。最直观的成果是提前期：三天预报的精度相当于此前模型两天的水平——多出的这一天，对沿海撤离决策是实打实的。合作方不是挂名，NHC、CIRA、UK Met Office 的人员直接出现在作者名单里。

要点：
- 论文 DOI 10.1038/s41586-026-10953-2，2026-08-06 发表于 Nature
- 集合成员从上一年的 50 个扩到 1,000 个，预报窗口 15 天，单次 15 天预报在 TPU 上耗时不到 1 分钟
- 模型已在 GitHub 开源（WeatherNext Cyclones / WeatherNext 2 / 2-mini）
- 合著者含 NHC（Zelinsky、Cangialosi、Franklin）、CIRA（DeMaria）、UK Met Office（Bain、Titley）

方法：在 20TB 大气再分析数据与约 5,000 场 IBTrACS 历史风暴上训练的集合式神经气象模型。
