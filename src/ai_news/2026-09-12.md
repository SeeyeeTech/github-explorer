- **三大 frontier 模型同周对撞**：GPT-6 Astra（Terminal-Bench 4.0 57.9%）、Claude Fable 5.1 / Mythos 5.1（55.8% / 60.9%）、Gemini 3.8 Flash（同时登 Agent / Code / Text 三榜 Top 10）→ 影响：开发者需按「档位-价格-能力」曲线选型，而非只看峰值。

#### 1. OpenAI 发布 GPT-6 Astra：首个达网络安全关键能力阈值的模型 · 🔥 必看 8.7

OpenAI 旗舰模型 GPT-6 Astra 在 Terminal-Bench 4.0 拿到 57.9%，超过 Claude Fable 5.1（55.8%）与 GPT-5.6 Sol（37.3%）；同价位 $10/$50 每百万 token，单任务成本相对 Fable 5.1 低约 63%，相对 GPT-5.6 Sol 低 9%。它是 OpenAI Preparedness Framework 下首个达「关键网络安全能力阈值」的模型。

要点：
- 在 Excel 财务建模赛上比人类冠军快约 4 倍（Financial Modeling World Cup）
- Computer use 不安全副作用比 Fable 5.1 少 74.7%，比 GPT-5.6 Sol 少 89%
- 工程轮延迟比前代降低 25×（代价峰值内存增加约 30%）
- 新增企业 admin 控制（网站/应用限制、上传/下载管理、浏览历史）+ 可选 Zero Data Retention

方法：在 GPT-5.6 Sol 基础上扩展 agent + long-context 训练，并新增 Preparedness Framework 关键阈值对齐。

CMU/Petuum 团队把离散扩散采样器（Ψ-Spec）与自回归 LLM 解耦，8B 模型相对基线 AR 在最大 batch 下仍保持最高 3× 无损加速，并在代码、长上下文、智能体工具调用上胜出。意义：把「推理加速只能放弃生成质量」这一长期权衡打破。
